# todo-cli-python
# 📝 To-Do List CLI App (Python)

A simple command-line To-Do list application written in Python.  
Allows you to **add**, **view**, **complete**, and **remove** tasks — all from your terminal.

---

## 🚀 Features

- ✅ Add new tasks
- 📋 View all tasks
- ✔️ Mark tasks as completed
- ❌ Delete tasks
- 💾 Save tasks to `todo.txt` for persistence

---

## 📦 Requirements

- Python 3.x
